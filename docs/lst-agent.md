## 支持条件与停止位置

本次只接入Landsat 8已提供大气辅助量与发射率的单通道辐射传输重建，不支持从普通RGB图推断温度，也没有接入下载大气资料、发射率估计、其他传感器或完整原始DN预处理。

输入为六波段TIFF，实际波段描述必须与同目录 `metadata.json` 的 `bands_in_order` 完全对应：

1. `thermal_radiance`：传感器热辐亮度。
2. `upwelling_radiance`：大气上行辐亮度。
3. `downwelling_radiance`：地表接收的下行辐亮度。
4. `atmospheric_transmittance`：无量纲透过率。
5. `surface_emissivity`：发射率。
6. `QA_PIXEL`：未缩放的整数质量位。

三种辐亮度单位为W/(sr·m²·μm)，值已应用源资产缩放；TIFF自身必须为单位缩放与零偏移，避免重复缩放。元数据需声明 `platform=landsat-8`、上述物理单位和来自该场景MTL的正数 `K1_BAND_10/K2_BAND_10`。旧样本透过率单位写成 `flag`，工具明确兼容该说明、按连续无量纲值检查0～1，不把它按二值旗标处理，也没有修改旧元数据。

工具要求可核对的米制投影网格，每幅不超过400万像元，最多8幅。NoData、非有限量、非整数QA、非正透过率/发射率、超出1的透过率/发射率、负大气辐亮度或非正校正辐亮度等均排除。填充、膨胀云、卷云、云、云影、积雪位0～5置位时排除，水体位本身不排除。质量位不保证全部云影响已消除，当前样本没有额外ST_QA或云距离筛选。

缺输入、单位不明、缺常数、未支持的方法/输出要求或只剩无效像元时明确停止。固定工具失败后不让工程师改写公式或忽略条件强行继续。温度变化、气温、指定模型、行政边界裁剪或只要CSV等额外需求当前不会被默认配方悄悄替换；保留需求为未完成。

## 计算和核验

以传感器辐亮度L、上下行辐亮度up/down、透过率tau和发射率e计算：

```text
B = (L - up - tau * (1-e) * down) / (tau * e)
T_C = K2 / log(1 + K1/B) - 273.15
```

不根据对照产品修正结果，也不截断到某个温度范围追分。实际热常数从本次元数据读取，不在算法里猜测默认常数。30米输出网格不表示热红外原生观测达到了30米精度。

参考：[辐射传输地温反演研究](https://www.mdpi.com/2072-4292/6/10/9829)、[CRAN LST包RTE输入说明](https://search.r-project.org/CRAN/refmans/LST/html/RTE.html)、[USGS Landsat产品的波段/质量位说明（Earth Engine目录）](https://developers.google.com/earth-engine/datasets/catalog/LANDSAT_LC08_C02_T1_L2)。这些来源支持物理输入与质量位含义，不代表本项目已复现USGS完整生产算法。

Executor只写本任务 `URSA_RESULTS_DIR`。计划锁定影像及元数据SHA256，执行前后均检查；Supervisor用同一版本从本次输入重新计算，检查温度像元、掩膜、单位、网格、方法JSON和CSV统计。这个检查能发现产物与声明算法不一致，但不能发现该算法共有的科学偏差，所以仍需独立评价。

输出包括 `final_lst_celsius.tif`（单波段degC、NaN缺测）、中文 `final_lst_preview.png`、`temperature_statistics.csv`、`method.json` 和 `lst_workflow.json`。计划、方法、输入、执行和最终图表均可随本次答卷封存。正常结果不包含MAE/RMSE等无参考依据的误差数字。
