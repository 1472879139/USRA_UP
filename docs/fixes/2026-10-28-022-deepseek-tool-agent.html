01 / 保留角色，连接工具循环

从原始需求走到可核对的交付

Manager保留原需求和修订，确认目标、数据范围及调用预算。
Scientist → Engineer锁定本次输入与计划，交给受控工具执行任务。
DeepSeek读取数据与能力摘要，选择工具和参数。
Executor检查白名单、参数、输入与产物ID，再执行真实工具。
返回 → DeepSeek收到结果或错误，决定继续、换适用工具或说明未完成。
Supervisor → Manager复核实际产物和收据，再展示结果图、事实与限制。

完成也需要证据

模型只用文字说“成功”不能结束。完成前必须核验当前产物，再通过finish_task引用实际产物ID；输出仍保留候选状态。

原Message、状态机、GUI/CLI和默认生成代码路径保留；新增字段均同步序列化和消费方。
