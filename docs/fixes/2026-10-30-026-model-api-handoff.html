能力选择与兜底归应用专用能力不适配时检查通用模型已接入任务；仍不能解决，再由 DeepSeek 代码路径处理或追问。目标变化必须说明。
服务保持明确行为按能力 ID 执行，不隐式换模型；不执行用户自由代码、不持有 DeepSeek 密钥；返回模型版本、统计与可下载产物。
当前 TerraMind 只接入地物分类，不等于支持所有遥感问题。田块边界提取与农作物类别分割不能无声互换。
