# URSA-UP 遥感任务测试案例与验收指标

编写日期：2026-10-22

## 1. 测试目的与执行顺序

本方案同时验证两个层面：

1. **系统层面**：Manager 是否正确分析需求，Scientist 是否完整接收已确认要求，Engineer 是否遵守约束，产物是否完整且按任务隔离。
2. **遥感层面**：波段与计算方法是否正确，栅格、统计表、图例和报告是否一致，是否如实说明语义精度与数据能力的限制。

建议顺序：案例1 → 案例2 → 案例5 → 案例3 → 案例4 → 案例6。

代码正常退出、文件存在、图像好看，都不能单独证明遥感解译正确。对缺少必要数据的任务，正确说明不能完成也是通过测试。

本次仅编写测试方法，没有运行智能体测试或调用付费模型。下列数值参考来自对本地影像的独立只读计算，而不是智能体生成的答案。

## 2. 测试数据与统一约定

输入文件：`data/Sentinel2_Dongcheng_20230718.tif`。

每个案例单独新建对话；案例5的多轮输入必须在同一对话内完成。正常计算任务应附上以下公共要求：

> 仅使用本地文件，不下载其他数据。测试统计范围定义为：各波段掩膜均有效，并排除全部10个波段同时为零的像元；这只是本次测试约定，不代表已验证的行政边界或云掩膜。输出到系统分配的本任务 results 子目录。报告应说明实际波段、计算方法、统计范围和限制，不编造精度。

### 2.1 数值基线的计算口径

- 统计掩膜：10个波段掩膜全部有效，全部波段值为有限数，且不属于全波段同时为零的像元。
- 指数计算：先将存储值转换为浮点数，再进行减法、加法和除法；分母为零的像元排除。
- 指数基线直接使用当前文件的存储值，不额外应用未经证实的缩放或偏移校正。
- 阈值统一使用严格大于 `>`，不是大于等于 `>=`。
- 面积为当前投影坐标下的平面面积：单像元面积为仿射变换行列式绝对值，本文件为100 m²，即0.0001 km²或0.01公顷。
- 比例分母为该指数有效统计像元数。本文件在上述约定下，NDVI和MNDWI的分母均为419,839。
- 统计使用全量像元，而不是预检缩略图或随机抽样结果。

**解释边界：** 文件未声明 NoData，排除全零像元是人为指定的测试规则；当前未证明产品级别、反射率编码、行政边界或云掩膜。下列指数值用于验证计算一致性，不应直接当作已经物理校正的反射率指数或真实地物面积。若更换文件、应用校正、改变掩膜、阈值或后处理，需要重新建立基线。

### 2.2 使用参考答案的方法

仅把“测试输入”和公共要求发给智能体，**不要把下列参考答案一起发送**。参考答案应由测试者在完成后独立比对，避免把复述答案误当成真实计算。

## 4. 案例2：NDVI计算与阈值敏感性

### 测试输入

> 对 data/Sentinel2_Dongcheng_20230718.tif 使用 B8 和 B4 计算 NDVI，运算前转换为浮点数，分母为零时排除。为验证计算流程，直接使用文件存储值，不进行未经证实的缩放或偏移校正。分别统计 NDVI严格大于0.2、0.3、0.4的像元数量、面积及占统计范围的比例。输出 NDVI GeoTIFF、带色标的 JPG 和统计 CSV。将结果称为阈值候选区域，不直接认定为真实植被覆盖面积。不进行平滑或其他改变阈值结果的后处理。

附上第2节公共要求。

公式：`NDVI = (B8 - B4) / (B8 + B4)`。

### 独立计算参考

| 条件 | 像元数 | 面积 km² | 占比 |
|---|---:|---:|---:|
| NDVI > 0.2 | 225,975 | 22.5975 | 53.8242% |
| NDVI > 0.3 | 171,111 | 17.1111 | 40.7563% |
| NDVI > 0.4 | 127,531 | 12.7531 | 30.3762% |

NDVI有效统计像元数：419,839；均值：0.2849115414；最小值：-0.5616；最大值：0.8702432938。

### 验收重点

- 正确定位波段，避免uint16直接相减导致下溢。
- 阈值升高时，候选区域面积不增加。
- 使用计算值生成统计，不能根据JPG颜色反推面积。
- 输出栅格保留原坐标系、仿射变换和尺寸，并对排除像元设置明确的无效值或掩膜。
- 明确这些是指定阈值下的候选区域，而非已验证的植被覆盖率。

## 5. 案例3：水体候选提取与误判分析

### 测试输入

> 对 data/Sentinel2_Dongcheng_20230718.tif 使用 B3 和 B11 计算 MNDWI，运算前转换为浮点数，分母为零时排除。为验证计算流程，直接使用文件存储值，不进行未经证实的缩放或偏移校正。分别提取 MNDWI严格大于0、0.1、0.2的候选区域，不做平滑、形态学处理或小斑块删除。输出指数 GeoTIFF、三个阈值的候选掩膜 GeoTIFF、对比 JPG 和统计 CSV。讨论阴影等混淆因素；没有参考样本时，不声称获得真实水体面积或提取精度。

附上第2节公共要求。

公式：`MNDWI = (B3 - B11) / (B3 + B11)`。

### 独立计算参考

| 条件 | 像元数 | 面积 km² | 占比 |
|---|---:|---:|---:|
| MNDWI > 0 | 8,866 | 0.8866 | 2.1118% |
| MNDWI > 0.1 | 3,562 | 0.3562 | 0.8484% |
| MNDWI > 0.2 | 2,391 | 0.2391 | 0.5695% |

MNDWI有效统计像元数：419,839；均值：-0.2579418678；最小值：-0.6904840303；最大值：0.7945066124。

### 验收重点

- 不与使用绿光、近红外的NDWI混淆。
- 三个候选掩膜与CSV逐像元统计相符。
- 不为“得到合理水体面积”擅自改变阈值或后处理。

### 9.1 数值误差判定

- 在完全相同的数据、统计掩膜和阈值约定下，候选像元数应完全一致。
- float32栅格与float64参考的普通指数值比较，可先用绝对误差1e-6作为开发检查容差。阈值边界应按原始计算值执行，不要先把指数舍入再分类。
- 面积和占比按输出小数位的四舍五入容差比较。例如面积保留4位小数时，比较误差不应超过0.00005 km²；这只允许数值展示误差，不能掩盖像元数量错误。
- 文件格式需检查实际内容，不是只看扩展名。JPG应能完整解码，GeoTIFF应能读取数据和地理参考，CSV应具有要求字段。

1. 连续执行两个新任务，确认分别位于两个 `results/task_年月日_时分秒_随机标识/` 目录。
2. 检查当前任务JPG、TIFF、CSV、报告和中间文件均在本任务目录。

## 10. 遥感语义精度评价

当前没有独立、可信的参考样本，不能给出该影像四分类的真实OA或F1。准备参考样本后，再计算：

| 指标 | 含义 |
|---|---|
| 总体精度OA | 全部验证样本中正确分类的比例 |
| 各类Precision／用户精度 | 预测为某类的样本中，真实属于该类的比例 |
| 各类Recall／生产者精度 | 真实属于某类的样本中，被正确识别的比例 |
| 各类F1 | 该类别Precision与Recall的调和平均 |
| Macro-F1 | 各类别F1的等权平均，避免多数类掩盖少数类问题 |

建议流程：

1. 明确定义类别，尤其区分建筑、建成区、道路与其他类别。
2. 准备与影像时间及空间范围相匹配、独立于训练和簇命名过程的参考标签。
3. 记录抽样方式、各类样本数及不确定样本的处理规则，避免只挑容易识别的位置。
4. 用预测标签和参考标签形成混淆矩阵，报告OA、逐类Precision、Recall、F1及样本数。某指标分母为零时应说明不可计算，不编造数值。
5. 若按类别不同比例抽样，面向全区的OA与面积估计应考虑抽样设计及权重，不能把样本比例直接当成全区比例。

无监督聚类的内部评价、模型自评、统计表数值一致性，都不能替代独立地物语义精度验证。面积统计也不等于带不确定度的真实面积估计。
