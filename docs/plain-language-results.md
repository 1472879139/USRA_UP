日期：2026-10-23。任务分支：`codex/plain-language-results`。

本批基于已推送的自动修复提交 `b430a6a`，保留其有限执行与核验修复循环。开发时检查主分支为 `eabcb14`，尚未合入该前置提交；后续合并须处理这一依赖，不能把两批任务误写成同一项改动。阶段图文中的提交与推送状态为当时快照，后续发布以Git记录为准；跨电脑运行见[资料迁移说明](migrate-to-another-computer.md)。

## 用户体验

1. 使用统一界面，无需切换模式。支持选择已有TIFF或添加TIFF影像；一次上传1～8个文件，总请求上限128MB。文件保存到新的 `data/uploads/<随机目录>/`，不覆盖原数据。
2. 可以查看最多512像素边长的缩略预览。预览采用显示拉伸，仅供选择数据，不用于定量计算或证明真实颜色。
3. 选好数据后用一句话提出问题。只选择数据、没有目标时先推荐用途；空目标的“自动分析”不会直接启动任意分析。
4. 输出默认卡片包含：原需求及修改、初步结论、图、统计表记录、检查与验证情况、需要留意的事项和下载入口。
5. 结果直接展示通俗说明；需要时在同一卡片内展开“专业详情”，查看方法、任务约定与检查依据。目录文件扫描独立放在对话区上方，默认收起，可用鼠标或键盘展开、收起，点击“刷新”保留展开状态。桌面分析管线恢复到右侧，进度、监督、追溯和导出入口独立于过程折叠状态。完整分析消息、代码和相关数据记录仍放在对话区的“查看分析过程与数据”中；最终结果出现后，原对话也归入该区域。默认结论不采用模型自称的可信百分比。
6. 刷新页面从当前状态恢复卡片；相同轮询快照不重置已展开的详情，新建会话清除旧结果与过程记录并收起详情。失败或缺少条件不会显示成功图。手机上也有新建对话、顶部目录扫描和展开过程的入口。窄屏沿用原界面在宽度不超过1100像素时隐藏右侧管线的规则。

代码更新后需要保存现有工作并重启程序。已有会话不会自动重跑；本批没有重启用户服务或运行收费分析。

## 任务约定与适用条件

`tools/task_contract.py` 保留原始需求、有序修订、辅助任务类型、目标对象和输入路径。明确选择的影像或需求中的可定位路径优先，GUI和CLI不再重新匹配其他文件。Manager、Scientist、Engineer及自动修复提示都接收同一记录。

任务类型的规则只辅助常见问题分流，不是任意中文需求的完整语义解析器。用户原文与有序修改始终优先；复杂多目标或模糊时间顺序仍需确认。记录和提示约束不等于操作系统级文件沙箱，也不能保证模型不会偏离方案。

当前检查包括：所选文件可用性、双时相至少需要两幅、已明确只有RGB时不能生成可靠温度。未确认的热红外单位和校正信息需要复核；无CRS时不承诺真实面积。RGB不被误判为天然无法识别建筑，但也不假定未接入的专业模型可用。

识别、变化、温度和去云结果当前保持候选或待验证状态。本批没有安装专业模型，没有修改原有温度函数，没有增加独立精度评分或按答案调参。后两批专业工具接入、任务专属核验和方法修复仍是待办。

## 共享接口

| 新增字段/接口 | 生产者 | 消费者与语义 |
|---|---|---|
| `Session.selected_inputs: list[str]`，默认空列表 | GUI文件选择；CLI可由需求中的路径定位 | Manager任务记录；值是data目录内的相对路径，确认控制指令不替换选择 |
| `Session.task_contract: dict`，默认空字典 | Manager确认/修订与Scientist进入规划 | 三角色、修复提示、GUI/CLI输入选择、结果卡片；原有confirmed_task原文接口不变 |
| `Session.task_capability: dict` | 确定性适用条件检查 | Scientist遇到blocked时在调用模型前返回ERROR；普通卡片翻译原因，专业详情保留完整记录 |
| `Session.result_delivery: dict` | Manager在核验后生成 | GUI状态快照、Session序列化与CLI通俗说明；独立验证不得由模型报告自行赋值 |
| `task_contract`追溯事件 | 任务约定改变时 | 沿用现有执行追溯/导出，不新增模型调用 |
| `Message.metadata.purpose=result_report` | Manager最终报告 | GUI更新事件保留purpose；完整报告归入可展开的分析过程，卡片内可查看专业说明 |
| `/api/chat.selected_inputs`，可选 | 浏览器 | 后端校验数据目录边界；原有不传此字段的调用兼容 |
| `/api/updates.result_delivery`与`selected_inputs` | 当前Session状态 | 浏览器刷新恢复，不依赖是否还有未读队列事件；无结果时为null |
| `GET /api/input_files`、`GET /api/input_preview?path=...` | 数据目录只读扫描 | 文件选择与有限缩略预览，不使用真实模型 |
| `POST /api/upload_inputs`，multipart的files字段 | 用户主动选择文件 | 验证TIFF头及实际格式；运行期间拒绝添加，失败只清理本批新文件 |
| `GET /api/result_file?path=...` | 核验清单 | 只提供当前任务内允许类型的实际文件；图片可预览，数值文件作为附件下载 |

原有Message类型、状态机枚举、approve控制语义、轮询游标和旧接口保留。`create_app(controller=None)`增加可选控制器注入，便于离线验证时不加载真实配置、不触发启动清理；正常运行方式不变。
