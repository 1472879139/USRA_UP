# 按任务隔离输出

每个新任务使用独立的 `results/task_年月日_时分秒_随机标识/` 目录，避免不同任务的同名文件互相覆盖。同一任务的确认、用户反馈和执行修复复用该目录，不为每次重试重新建目录。

Engineer 生成代码时读取执行器提供的 `URSA_RESULTS_DIR` 环境变量。地图、栅格、统计表、报告及中间数据统一保存到这个绝对路径下。共享 IO 工具在执行子进程中也遵守该目录；独立使用工具且未设置环境变量时保留原有默认行为。

执行器会创建任务目录，记录实际路径，并将写到本任务目录以外的结果作为执行错误交回 Engineer 修复。产物核验只接受当前任务目录下的文件。这是输出约定和执行后核验，不是操作系统级文件写入沙箱；误写文件不会被自动删除或搬移。

历史结果保持原样，不自动迁移。重启程序后创建的新任务采用此约定。
