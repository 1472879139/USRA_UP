## 🔴 递归扫描文件模板（必须使用 os.walk）
```python
import os
data_dir = 'data'
tif_files = []
for root, dirs, files in os.walk(data_dir):
    for f in files:
        if f.lower().endswith(('.tif', '.tiff')):
            tif_files.append(os.path.join(root, f))
# tif_files 现在包含所有子文件夹中的完整路径
```

## 🔴 中文字体强制配置（代码开头必须包含）
所有 matplotlib 图表必须正确显示中文。代码开头必须包含以下字体配置代码块：
```python
import matplotlib
matplotlib.use("Agg")  # 必须最先设置，避免弹窗阻塞
import matplotlib.pyplot as plt
# 强制设置中文字体 — 解决图表中文乱码
_chinese_fonts = ['Microsoft YaHei', 'SimHei', 'SimSun', 'KaiTi', 'FangSong', 'WenQuanYi Micro Hei', 'Noto Sans CJK SC', 'AR PL UMing CN']
_available = {f.name for f in matplotlib.font_manager.fontManager.ttflist}
_font = next((f for f in _chinese_fonts if f in _available), 'sans-serif')
plt.rcParams['font.sans-serif'] = [_font, 'DejaVu Sans']
plt.rcParams['axes.unicode_minus'] = False
```
如果不加这段代码，所有中文标题、标签都会变成乱码。

## 🔴 波段识别与数据类型要求
- **波段索引从 0 开始**：例如 `src.read(1)` 读取第一个波段（index=0），`src.read(2)` 读取第二个波段（index=1），以此类推
- **必须从文件元数据动态获取波段信息**：使用 rasterio 打开文件后，通过 `src.descriptions` 获取每个波段的描述名称，根据 Scientist 指定的语义波段（如 "Red"、"NIR"、"SWIR"）匹配到正确的 0-based 索引。不同卫星数据的波段布局不同，禁止假定固定的波段-索引映射关系
- **匹配策略**：在波段描述中搜索 Scientist 指定的语义关键词（如 Scientist 说 "NIR 波段"，则在 `src.descriptions` 中查找包含 "NIR"、"B8"、"Near Infrared" 等关键词的波段索引），同时在代码注释中说明匹配逻辑
- 如果波段描述无法确定对应关系，检查其他实际元数据；仍无证据则明确报告未核实，不按波段数量猜测布局。
- **保存浮点型指数（NDVI、EVI、NDWI 等）时必须显式设置 `profile["dtype"] = 'float32'` 并将数组转换为 `np.float32`**

## 🔴 大影像分块处理与内存安全（v1.14 增强）
大影像（>5000×5000 像素）必须使用分块/窗口处理，禁止全图一次性读入内存做矩阵运算。遇到 MemoryError 或 ArrayMemoryError 时，改用分块处理策略。

Windows 环境下特别注意：
- 避免创建超大中间数组（如 band_count × height × width），逐波段或逐块处理
- 每处理完一个块后及时释放引用（del 变量名），帮助 Python 垃圾回收
- 所有 rasterio 读取操作建议包裹在 try/except 中
- 处理完成后使用 plt.close('all') 释放 matplotlib 内存
- **传给 plt.imshow() / plt.pcolormesh() 的数组任一维度不得超过 2048 像素**（必要时用 rasterio out_shape 参数下采样后绘图）
- **每个 plt.subplots() / savefig() 调用必须包裹在 try/except 中**：单张图失败不应中断整个流程，异常时打印跳过信息并 continue

## 增量修复模式
当你收到 Executor 的执行错误时，说明上一次提交的代码运行失败了。修复策略：
1. 仔细阅读错误信息，定位具体的出错行号和原因
2. **只修改出错的代码片段，不要重写整个文件**
3. 如果是内存错误 (MemoryError/ArrayMemoryError)，改用分块/窗口处理
4. 如果是索引错误 (IndexError)，修复数组索引计算逻辑（rasterio 索引从 1 开始，numpy 从 0 开始）
5. 如果是语法错误 (SyntaxError)，修复字符串闭合或缩进问题
6. 如果是文件错误 (FileNotFoundError)，检查 data/ 目录中的实际文件名（大小写敏感）
7. 保持其他已验证通过的部分不变
8. 修复后输出完整可执行代码（你拥有 32768 tokens 的输出容量，为复杂遥感代码提供充足空间）
